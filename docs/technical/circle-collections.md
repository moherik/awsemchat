# Encrypted Circle collections

MVP product scope: members contribute app-created stickers; admins remove shared entries. Each Circle has its own sticker collection. Explicit personal sticker copies remain available after shared removal. Chat and Moment reactions use standard emoji. Custom Circle emoji are deferred beyond the MVP. The existing protocol's `emoji` kind is reserved and is not exposed by the Android MVP UI. New members receive a freshly encrypted current collection, never prejoin chat/Moment history. Media and descriptors remain end-to-end encrypted; Supabase is unconfigured, so implementation uses the local private media gateway first.

## Implementation sequence

1. Give shared mutations a dedicated `circle-collection` envelope type, authenticated encrypted routing metadata, separate `collectionRevision`, and `collectionChange:{action,kind,item}`. For MVP mutations, the server sees only add/remove, sticker kind, opaque item ID and revision, alongside existing conversation/audience metadata. It must never receive labels, image bytes, media keys or maker composition in plaintext.
2. Commit revision, immutable shared item IDs and ciphertext event/deliveries in the existing message transaction. Use current member/audience/epoch checks; only current admins remove. Exact retries reconcile before checking later state. Deleted IDs remain tombstoned so delayed additions cannot revive them. Profile revisions remain independent.
3. Extend native durable encrypted payloads, retry/history/archive/receive binding and client DTOs; reject mismatched decrypted mutation metadata. Native sender history marks only server-accepted collection updates as accepted. Existing clients must not render these control events as chat text.
4. Add strict encrypted add/remove payload validation, ordered projection and current-collection snapshots for joined members. Fresh snapshots copy current media to new encrypted objects/keys; never widen old grants. Deletions must win against old snapshots and restored historical events.
5. Add account-bound protected media/mutation recovery, shared management/picker UI, app sticker-maker integration and explicit personal copy storage. Admin removal changes the shared picker only; original chat media and explicit personal copies are not recalled.
6. Verify local PostgreSQL/HTTP, actual native encryption, media, restart/retry, join/remove/rejoin, copies and backup completeness. Record provider/device acceptance separately; emulator tests remain skipped by the owner.
