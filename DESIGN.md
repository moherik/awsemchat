# AwsemChat visual direction

User reference: classic BBM mobile application screenshot, supplied 2026-10-10. The reference establishes application density and familiar Android chrome, not its public feeds/discovery features.

Direction: an everyday personal messenger. Compact contact rows with actual avatar images, clear message previews, understated timestamps, inset separators. A 56px toolbar with icon actions; a 64px bottom navigation bar with icons and labels. Three category pills retain the agreed All / Private / Circles filter. A single blue floating compose action has elevation because it sits over scrollable conversations.

Light theme: white content, cool gray chrome, dark charcoal typography, BBM blue at selected navigation and primary composition. Dark theme follows the same hierarchy. System fonts preserve native Android/iOS familiarity. Material icons use a substantial filled weight consistent with the reference.

Conversations use a compact identity header, readable bubbles, discreet delivery marks, inline media, an icon composer, and contextual actions. Settings use list rows and disclosures, not grids of outlined buttons. Demo identification lives once in app chrome; technical simulation controls are kept out of ordinary product screens.

ENERGY 2 / RHYTHM 1 / MOTION 1. Emoji are communication content, not decorative UI icons. No gradient, glow, glass, or card-based chat list.
